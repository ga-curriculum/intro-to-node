## What is Node.js?

Node.js is a CLI tool that will execute JavaScript code in your terminal. N. de’s environment for JS is different than that in the browser, primarily because:

  - It doesn’t have a browser’s DOM or [Web APIs](https://developer.mozilla.org/en-US/docs/Web/API).
  - Node can access your computer's networking capabilities and file system.

In addition to being used to build high-performance web server applications, Node is also a great tool for building command-line applications and utilities. Node is very lightweight, containing only core modules for networking, filesystem access, etc.

Open-source libraries called packages extend Node’s functionality. Node’s package ecosystem is the largest open-source ecosystem in the world.
