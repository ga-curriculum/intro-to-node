# ![Intro to Node](./assets/hero.png)

## About

In this module, we'll explore the exciting world of Node.js, a powerful and versatile JavaScript runtime that has revolutionized how we build scalable and efficient web applications with JavaScript on the back-end. From understanding the basics of Node.js and its ecosystem, including NPM (Node Package Manager), to importing and utilizing real Node packages, this module gives learners a practical introduction this powerful new tool.

We'll unravel the reasons behind Node.js's widespread adoption and highlight its performance benefits and the flexibility it creates for full-stack development.

## Prerequisites

- Intro to Full-Stack Development
- HTTP Request Response Cycle
